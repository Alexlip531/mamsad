# Мамсад — Мамы ищут садик 🌱

Android-приложение для мам, которые ищут идеальный садик для своего ребёнка. Каталог обновляется напрямую с сайта [mamsad.ru](https://mamsad.ru/) через WordPress REST API: частные и муниципальные сады, развивающие центры, няни и репетиторы в Королёве и Мытищах.

## Возможности

- **Каталог садиков** с фильтрами по городу, типу и категории
- **Подробное описание** каждого учреждения
- **Избранное** — сохраняйте понравившиеся сады
- **Прямая ссылка** на mamsad.ru для записи на экскурсию
- **Поделиться карточкой** садика с семьёй
- **Pull-to-refresh** — актуальные данные всегда под рукой

## Дизайн

Тёплая палитра в духе «мама + ребёнок + росток»:

- 🟠 Коралловый (основной) — тепло материнской заботы
- 🟢 Шалфейный (вторичный) — рост и развитие
- 🟡 Солнечный (акцент) — детская радость
- 🟣 Лиловый (акцент) — нежность и воображение
- 🤍 Кремовый (фон) — уют

## Архитектура

- **Kotlin + Material 3** — современный UI
- **MVVM + StateFlow** — реактивная архитектура
- **Room** — локальный кэш и избранное (работает офлайн)
- **Retrofit + Moshi** — мост к WordPress REST API mamsad.ru
- **Coil** — загрузка изображений
- **Navigation Component** — навигация между экранами
- **ViewBinding** — типобезопасный доступ к view

## Источник данных

Приложение является мостом к сайту [mamsad.ru](https://mamsad.ru/) и использует его публичный WordPress REST API:

- `GET /wp-json/wp/v2/kg_org` — список организаций (садов)
- `GET /wp-json/wp/v2/kg_city` — города
- `GET /wp-json/wp/v2/kg_org_type` — типы учреждений
- `GET /wp-json/wp/v2/kg_org_category` — категории услуг

## Сборка

```bash
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

CI через GitHub Actions автоматически собирает APK при пуше в `main` и публикует релиз.

## Скриншоты

Главный экран:
- Приветствие «Здравствуйте, мама!»
- Иллюстрация сердце + росток
- Счётчик садиков в каталоге
- Быстрые фильтры по городам
- Список свежих садиков

Каталог:
- Поиск по названию
- Активные фильтры (удаляемые чипы)
- Карточки садиков с типом, городом, описанием
- Кнопка избранного на каждой карточке

Фильтры:
- Поиск по названию
- Город (Королёв / Мытищи)
- Тип (Частный / Муниципальный / Развивающий центр)
- Категории услуг
- Сортировка (новые / по алфавиту / по городу)

Детали:
- Hero-блок с градиентом
- Название, город, тип
- Теги (категории)
- Описание
- Ссылка на mamsad.ru
- Кнопки «В избранное» и «Поделиться»
