# Мамсад — Админ-панель

Веб-интерфейс для управления каталогом детских садов в приложении Мамсад.

## Что делает админка

- 📋 **Каталог mamsad.ru** — все 12 садиков синхронизированы с сайтом
- ⭐ **Топ** — закрепляйте выбранные садики в начале списка
- 👁️ **Скрыть** — убирайте садики из приложения, не трогая mamsad.ru
- ✏️ **Правки** — заменяйте название, описание, адрес, цену, рейтинг, координаты
- 🏷️ **Кастомные теги** — добавляйте свои теги для садика
- ➕ **Кастомные садики** — добавляйте свои садики, которых нет на mamsad.ru

## Как это работает

```
┌─────────────────┐      ┌─────────────────┐      ┌─────────────────┐
│  Админ-панель   │ ───▶ │ /api/save       │ ───▶ │ GitHub API      │
│  (этот сайт)    │      │ (Next.js route) │      │ commits JSON    │
└─────────────────┘      └─────────────────┘      └────────┬────────┘
                                                          │
                                                          ▼
                                                 admin/overrides.json
                                                          │
                                                          ▼
┌─────────────────┐      ┌─────────────────┐      ┌─────────────────┐
│  Приложение     │ ◀─── │ MamsadRepository│ ◀─── │ raw.githubuser  │
│  Мамсад (APK)   │      │ fetches & merges│      │ content.com URL │
└─────────────────┘      └─────────────────┘      └─────────────────┘
```

1. Вы вносите изменения в админ-панели
2. Нажимаете **«Сохранить»**
3. Сервер коммитит `admin/overrides.json` в GitHub
4. Приложение при следующем обновлении скачивает этот файл
5. Применяет ваши правки поверх данных mamsad.ru

## Локальный запуск

```bash
# 1. Установить зависимости
bun install

# 2. Создать .env.local с GitHub PAT
echo 'GITHUB_TOKEN=ghp_ВАШ_ТОКЕН' > .env.local
# Получить токен: https://github.com/settings/tokens (нужен scope 'repo')

# 3. Запустить
bun run dev
# Откройте http://localhost:3000
```

## Деплой на Vercel

### Шаг 1. Форкните репозиторий

```bash
git clone https://github.com/Alexlip531/mamsad.git
cd mamsad/admin-panel  # или где находится Next.js приложение
```

### Шаг 2. Импортируйте в Vercel

1. Откройте https://vercel.com/new
2. Выберите ваш форк репозитория
3. Vercel автоматически определит Next.js

### Шаг 3. Добавьте переменную окружения

В настройках проекта на Vercel:

- **Key**: `GITHUB_TOKEN`
- **Value**: ваш GitHub Personal Access Token (scope: `repo`)
- Получить токен: https://github.com/settings/tokens

### Шаг 4. Деплой

Нажмите **Deploy**. Через ~1 минуту админка будет доступна по адресу вида:
`https://mamsad-admin-xxxx.vercel.app`

## Структура проекта

```
src/
├── app/
│   ├── page.tsx              # Главная страница админки
│   ├── layout.tsx            # Layout с шрифтами и тоастером
│   ├── globals.css           # Tailwind стили
│   └── api/
│       ├── state/route.ts    # GET: загрузка orgs + overrides
│       └── save/route.ts     # POST: коммит overrides.json в GitHub
├── components/
│   └── ui/                   # shadcn/ui компоненты
└── lib/
    └── utils.ts              # Утилиты
```

## Технологии

- **Next.js 16** (App Router)
- **TypeScript 5**
- **Tailwind CSS 4**
- **shadcn/ui** — UI компоненты
- **Lucide Icons** — иконки
- **GitHub REST API** — для коммитов overrides.json

## Безопасность

- ⚠️ **GITHUB_TOKEN** хранится только в переменных окружения сервера, никогда не попадает в браузер
- ⚠️ Токен должен иметь scope `repo` для записи в `admin/overrides.json`
- ⚠️ После настройки админки **отзовите старый токен** на https://github.com/settings/tokens и создайте новый с минимальными правами

## Скриншоты

Главный экран:
- Сверху: оранжево-зелёный градиент в стиле Мамсад
- Статистика: всего / топ / с правками / скрыто
- Каталог mamsad.ru с переключателями Топ/Видим и кнопкой Изменить
- Кнопка «Добавить садик» для кастомных организаций

Карточка садика:
- Toggle «Топ» — закрепить в начале
- Toggle «Видим» — показать/скрыть
- Кнопка «Изменить» — открыть форму правок
- Иконка external link — открыть на mamsad.ru

Форма редактирования:
- Своё название / описание / адрес / цена
- Координаты (широта, долгота)
- Рейтинг (0–5)
- Кастомные теги (через запятую)
- Топ / Скрыть переключатели

Форма добавления кастомного садика:
- Все поля редактирования +
- Город, тип, телефон, сайт
- Полное описание (HTML)
